# 黄金CRM

公司岗位协作、业务架构资料与可交互的 CRM 概念 MVP。应用位于 `demo`，后端、支付、小程序 API、金银行情和 AI 均采用模拟数据。

## 查看概念 MVP

在 `demo` 目录执行 `npm ci`、`npm run dev`，浏览器打开 http://127.0.0.1:5173/。仅监听本机；当前浏览器操作会保存，换浏览器有独立数据。

已按确认的 12 个一级导航实现：工作台、客户与跟进、销售与订单、售后与服务、商品与设计、采购与库存、工厂与质检、营销中心、财务管理、数据统计、行情中心、系统与集成。

- [使用与验证说明](demo/README.md)：操作路径、数据口径、启动及检查命令。
- [验收记录](demo/验证记录.md)：12 个导航的交互验证、文件说明及当前限制。
- [产品范围](PRODUCT.md)：岗位、业务边界与共享记录约定。
- [设计约定](DESIGN.md)：Oil UI Pro 主导的深色协作工作台。

会员是客户下的身份与消费记录；销售登记和财务核验共用同一笔收退款。模拟行情不会覆盖历史报价与采购成本。实际岗位、行业计价及损耗口径仍须商家确认。
