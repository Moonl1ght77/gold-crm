## 演示边界

后端、数据库、支付、小程序 API 和金银行情均模拟；AI 是读取同一业务记录的本地确定性查询，未接外部大模型。活动状态只在本地保存，不对外发布。

数据保存在当前浏览器的 localStorage；金额为整数分、重量为整数毫克，界面显示元与克。换浏览器拥有独立数据，未验证跨浏览器多人并发；保存失败保留原记录和输入，损坏存档不自动覆盖。

真实负责人、兼岗、权限、计价、损耗、成本分摊及接口字段仍须商家核实。本版用于讨论流程，不承担生产财务或真实客户业务。
