# 黄金CRM 设计思路（讲解版）

> 2026-10-11。用来跟商家口头讲思路，不给商家看虚拟演示；需求理清前，点击原型先搁置。

## 一句话

给金店做一套全公司在企业微信里用的系统：客户和订单一条线跟到底，每件货用了什么料、花了多少钱都算得清。

## 想解决的问题（待商家确认）

- 客户、订单散在微信和表格里，交接靠人记，出了问题追不回去。
- 一件货常是金、K 金、银、钻、彩钻、珐琅组合，用了多少料、成本多少说不清。
- 每批料的去向对不上：余料、回收、损耗、在制混在一起。
- 门店和小程序各有一本账。

## 三条主线

1. **业务单**：需求 → 报价 → 立单 → 备货生产 → 质检交付 → 售后；每一步谁负责、留了什么记录，随时能追。
2. **原料批次**：每批料按自己的单位对账（金银按克，宝石按粒和克拉）；成品成本和毛利由实际用料算出，不靠手填。
3. **岗位入口**：老板、店长、顾问、仓库、工厂、财务各看各的工作台；审批按金额逐级上转。

## 先跟商家问清的 5 件事

1. 店里有哪些岗位、谁管什么，有没有兼岗。
2. 怎么计价：按克加工费还是一口价，金价看哪里。
3. 用哪些原料，宝石怎么管（单粒带证书还是按包）。
4. 损耗和余料现在怎么记、谁确认。
5. 小程序是哪家做的，现在用不用企业微信。
